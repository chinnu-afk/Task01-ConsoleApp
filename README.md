# Task 01 - Console app with classes

## What this project demonstrates
- Three classes: `Product`, `Inventory`, and `Program`.
- Properties rather than public fields.
- A constructor that validates product name and price.
- Input validation for null products.
- Readable console output.

## Expected output
Inventory
---------
Notebook - ₹55.00
Pen - ₹12.50
Backpack - ₹799.00
Total products: 3

## How to run
Requires the .NET 8 SDK.

From this folder, run:
    dotnet run
